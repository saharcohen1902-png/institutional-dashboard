# מעקב החזקות מוסדיות — 13F + COT

ממשק שמציג את ההחזקות הגדולות של מוסדות ההשקעה הגדולים בארה"ב מתוך דוחות
**13F-HR** של ה-SEC, יחד עם עמודת חוזים המבוססת על דוח **COT** השבועי של ה-CFTC.
הטבלאות מתעדכנות אוטומטית בכל פעם שמתפרסמים נתונים חדשים.

## מוסדות במעקב
- **מנהלי נכסים:** בלאקרוק, ונגארד, סטייט סטריט
- **בנקים:** ג'יי פי מורגן צ'ייס, בנק אוף אמריקה
- **חברות ביטוח:** ברקשייר האת'וויי, מטלייף

לכל מוסד: טבלת 5 הרבעונים האחרונים (שנה + רבעון בסיס), 25 ההחזקות הגדולות עם
שינוי רבעוני (הגדלה/הקטנה/חדש/יציאה), ושווי אופציות PUT/CALL מתוך הדיווח.

## הרצה
```bash
python3 update.py       # מושך 13F + COT ובונה מחדש את data.json
python3 serve.py 4200   # http://127.0.0.1:4200/
```

## עדכון אוטומטי
```bash
./schedule.sh install    # מריץ update.py כל יום ב-23:17 (LaunchAgent)
./schedule.sh status
./schedule.sh uninstall
```
דוח COT מתפרסם בכל יום שישי 15:30 ET; ההרצה היומית לוכדת אותו וכן כל 13F חדש.
אפשר גם ללחוץ על `/refresh` בשרת כדי להריץ עדכון ידני ברקע.

## קבצים
| קובץ | תפקיד |
|------|-------|
| `config.py` | רשימת המוסדות (קבוצות CIK) והחוזים |
| `fetch_13f.py` | משיכה + פענוח של טבלאות 13F, טיפול בתיקונים (amendments) |
| `fetch_cot.py` | משיכת COT מ-CFTC Socrata |
| `build_site.py` | בונה את `web/data.json` |
| `update.py` | מריץ את שלושת השלבים ברצף |
| `serve.py` | שרת מקומי + `/refresh` |
| `web/index.html` | הממשק (עברית, RTL, מצב כהה) |

## הערות על הנתונים
- **ריבוי ישויות מדווחות:** ונגארד ובלאקרוק מדווחים דרך כמה CIK-ים שמתחלפים
  לאורך זמן; המערכת מאחדת אותם. מטלייף — התיק האמיתי מדווח דרך
  *MetLife Investment Management*, לא דרך חברת האם.
- **תיקונים (Amendments):** דיווח RESTATEMENT מחליף את הדיווח המקורי לאותו רבעון;
  דיווח NEW HOLDINGS מתווסף. המערכת מזהה גם תיקונים שסומנו שגוי (לפי חפיפת ניירות).
- **ערכים:** משנת 2023 ה-SEC עברה לדיווח בדולרים מלאים במקום אלפי דולרים; מטופל אוטומטית.
- מקורות רשמיים בלבד (SEC EDGAR, CFTC). זה כלי מעקב נתונים — לא ייעוץ השקעות.
